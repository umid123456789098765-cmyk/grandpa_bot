# Бот-помощник для пожилых людей

Telegram-бот с крупными кнопками: напоминания, простое общение, кнопка
«позвонить родным» и автоматическая проверка активности (если дедушка
долго не выходит на связь — бот пишет родственникам).

## Обязательная подписка на канал

Теперь бот не пускает пользователя дальше `/start`, пока тот не подпишется
на ваш Telegram-канал.

**Настройка (2 шага):**

1. Добавьте бота **администратором** в свой канал (без этого бот не сможет
   проверять подписчиков — Telegram просто не даёт такую информацию обычным
   участникам).
2. Задайте в `config.py` (или через переменные окружения) два значения:
   ```python
   REQUIRED_CHANNEL_USERNAME = "@ваш_канал"
   REQUIRED_CHANNEL_URL = "https://t.me/ваш_канал"
   ```

Как это выглядит для пользователя: при `/start` бот показывает кнопку
«📢 Подписаться на канал» и кнопку «✅ Я подписался». После подписки и
нажатия второй кнопки бот присылает сообщение из `AFTER_SUBSCRIBE_MESSAGE`
(тоже в `config.py`) и открывает обычное меню. Проверка происходит и при
каждом последующем действии — если человек отпишется от канала, бот снова
попросит подписаться.

## Как всё устроено

- `bot.py` — точка входа, запускает бота
- `handlers.py` — вся логика диалогов (напоминания, привязка родных, чат)
- `database.py` — хранение данных в SQLite (файл `grandpa_bot.db` создаётся автоматически)
- `scheduler.py` — фоновые задачи: рассылка напоминаний, ежедневный вопрос
  «как дела», проверка молчания
- `keyboards.py` — крупные кнопки для дедушки и для родственника
- `config.py` — настройки (токен, время проверок)

Один и тот же бот работает и для дедушки, и для родственника — роль
выбирается при первом запуске (`/start`).

## Запуск за 5 шагов

1. **Получите токен бота.**
   В Telegram напишите @BotFather → `/newbot` → следуйте подсказкам.
   Скопируйте токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`.

2. **Установите зависимости** (нужен Python 3.10+):
   ```bash
   pip install -r requirements.txt
   ```

3. **Задайте токен** через переменную окружения:
   ```bash
   export BOT_TOKEN="ваш_токен_сюда"
   ```
   (или впишите его прямо в `config.py` в строку `BOT_TOKEN`)

4. **Запустите бота:**
   ```bash
   python bot.py
   ```

5. Откройте бота в Telegram и нажмите **Start**.

## Как пользоваться

**Дедушка/бабушка:**
- При первом запуске выбирает «Я бабушка/дедушка»
- Дальше всё через большие кнопки внизу экрана — команды писать не нужно

**Родственник:**
- Тоже открывает бота и выбирает «Я родственник»
- Дедушка нажимает «📞 Позвонить внукам» → бот выдаст ему код
- Родственник нажимает «🔗 Привязать по коду» и вводит этот код
- После этого родственник будет получать:
  - сообщение, когда дедушка хочет поговорить
  - сообщения о самочувствии
  - тревогу, если дедушка не выходит на связь дольше 20 часов (настраивается в `config.py`)

## Чтобы бот работал, даже когда ваш ПК выключен

Сейчас бот запускается на вашем компьютере — как только вы закроете VS Code
или выключите ПК, бот перестанет отвечать. Чтобы он работал круглосуточно,
его нужно перенести на сервер (VPS), который никогда не выключается.

**Рекомендация для новичка:** [Timeweb Cloud](https://timeweb.cloud) —
российский хостинг с понятным интерфейсом, поддержкой на русском языке и
недорогими тарифами (от ~150–450 ₽/мес для такого лёгкого бота). Подойдёт
и любой другой VPS с Ubuntu — шаги будут теми же.

### Пошагово

1. **Арендуйте VPS** с Ubuntu 22.04 (в панели хостинга выбирается при
   создании сервера — обычно это пара кликов).

2. **Подключитесь к серверу.** Хостинг выдаст вам IP-адрес и пароль.
   Проще всего подключиться прямо из VS Code:
   - Установите расширение **Remote - SSH** (значок с квадратиками слева →
     поиск "Remote - SSH" → Install)
   - `Ctrl+Shift+P` → «Remote-SSH: Connect to Host» → введите
     `root@ваш_ip_адрес` → введите пароль от сервера

3. **Установите Python и git на сервере** (в терминале VS Code, который
   теперь подключён к серверу):
   ```bash
   apt update && apt install -y python3 python3-pip python3-venv
   ```

4. **Скопируйте файлы бота на сервер** — проще всего перетащить всю папку
   `grandpa_bot` в проводник файлов VS Code слева (он покажет файловую
   систему сервера, когда вы подключены через Remote-SSH).

5. **Установите зависимости и токен:**
   ```bash
   cd grandpa_bot
   pip install -r requirements.txt
   export BOT_TOKEN="ваш_токен"
   export REQUIRED_CHANNEL_USERNAME="@ваш_канал"
   export REQUIRED_CHANNEL_URL="https://t.me/ваш_канал"
   ```

6. **Настройте автозапуск через systemd**, чтобы бот сам перезапускался
   при сбое или перезагрузке сервера. Создайте файл:
   ```bash
   nano /etc/systemd/system/grandpabot.service
   ```
   Вставьте (замените пути и токен на свои):
   ```ini
   [Unit]
   Description=Grandpa Bot
   After=network.target

   [Service]
   WorkingDirectory=/root/grandpa_bot
   ExecStart=/usr/bin/python3 /root/grandpa_bot/bot.py
   Environment="BOT_TOKEN=ваш_токен"
   Environment="REQUIRED_CHANNEL_USERNAME=@ваш_канал"
   Environment="REQUIRED_CHANNEL_URL=https://t.me/ваш_канал"
   Restart=always
   RestartSec=5

   [Install]
   WantedBy=multi-user.target
   ```
   Сохраните (`Ctrl+O`, `Enter`, `Ctrl+X`), затем запустите:
   ```bash
   systemctl daemon-reload
   systemctl enable grandpabot
   systemctl start grandpabot
   ```

7. **Проверьте, что бот работает:**
   ```bash
   systemctl status grandpabot
   ```
   Должно быть написано `active (running)`. Теперь бот будет работать
   постоянно — даже если вы выключите свой компьютер или сервер
   перезагрузится.

   Посмотреть логи бота в любой момент: `journalctl -u grandpabot -f`

## Что можно улучшить дальше

- Подключить голосовой ввод (Telegram поддерживает голосовые сообщения — можно
  через Whisper API распознавать их в текст)
- Более "живой" чат — сейчас ответы простые и заготовленные; можно подключить
  Claude API, чтобы бот отвечал осмысленно на любые сообщения
- Несколько напоминаний с разной периодичностью (не только ежедневно)
- Хранение телефона родственника, чтобы дедушка видел номер прямо в боте

## Важно перед запуском на постоянной основе

- Бот должен работать на сервере (или компьютере, который не выключается),
  чтобы напоминания и проверки активности продолжали работать
- Для реального использования лучше развернуть на простом VPS
  (например, через systemd, чтобы бот перезапускался при сбоях)
